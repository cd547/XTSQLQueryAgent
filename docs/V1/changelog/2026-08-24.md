## 一、功能修复

### F1. 思考模式 reasoning_effort 字段位置错放（后端 / llm.js）

- 现象：用户在 UI 选"中"或"高"档后，问问题聊天页 **看不到** `💭 LLM思考过程` 折叠项，`delta.reasoning_content` 始终为空字符串。
- 根因：`buildThinking(reasoningConfig)` 错误地把 `reasoning_effort` 嵌套在 `thinking` 对象内：
  ```js
  // 错误：DeepSeek Chat Completions API 不识别嵌套字段
  { thinking: { type: 'enabled', reasoning_effort: 'medium' } }
  // 正确：reasoning_effort 必须与 thinking 平级
  { thinking: { type: 'enabled' }, reasoning_effort: 'medium' }
  ```
  DeepSeek 官方文档（[create-chat-completion](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion)）明确把 `reasoning_effort` 放在请求体顶层。
- 修复：改用 spread 展开，让 `thinking` 和 `reasoning_effort` 平级；修复后 `delta.reasoning_content` 流式返回非空。
- 提交：`3126dba`；后端 `--watch-path=src` 自动重载生效。

### F2. Responses API 路径漏传 reasoningConfig（后端 / responsesApi.js + query.js）

- 现象：用户在 `agent_config` 切到 `apiMode=responses_api` 后报错 `ReferenceError: reasoningConfig is not defined`。
- 根因：
  1. [responsesApi.js:712](file:///d:/Ai_Program_Files/XTSQLQueryAgent/backend/src/services/responsesApi.js#L712) `runSqlAgentResponsesHandler` 的 destructure 漏写 `reasoningConfig` 字段；
  2. [query.js:428-453](file:///d:/Ai_Program_Files/XTSQLQueryAgent/backend/src/routes/query.js#L428-L453) 调用 `runSqlAgentResponsesHandler` 时 ctx 未传 `reasoningConfig: reasoning`。
  两处叠加导致 generator 函数内部 `reasoningConfig` 引用未声明。
- 修复：两处分别补全 `reasoningConfig` 字段，CC/Responses 双路径对齐。
- 提交：`3126dba`；后端自动重载。

### F3. 前端 reasoningEnabled 状态硬编码 false（前端 / App.jsx）
